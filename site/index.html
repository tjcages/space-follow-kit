SpaceFollowKit

v0.1.0 / GitHub

Make macOS subwindows follow Spaces with correct z-order and no swipe-time “always on top” glitch.

Behavior

Space-aware

Handoff

Deterministic

Integration

SwiftUI-first

Installation

$ swift package add https://github.com/tjcages/space-follow-kit.git

Usage

import SpaceFollowKit

Window("Quick Capture", id: "quick-capture") {
  QuickCaptureView()
    .subwindowSpacesBehavior(storageKey: "subwindowsOnAllSpaces")
}

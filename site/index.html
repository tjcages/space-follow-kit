SpaceFollowKit

Deterministic macOS Space handoff for real floating subwindows.

Subwindows follow Spaces with correct z-order and no swipe-time always-on-top glitch — SwiftUI-friendly, zero configuration.

Installation

$ swift package add https://github.com/tjcages/space-follow-kit.git

Usage

import SpaceFollowKit

Window("Quick Capture", id: "quick-capture") {
  QuickCaptureView()
    .subwindowSpacesBehavior(storageKey: "subwindowsOnAllSpaces")
}
